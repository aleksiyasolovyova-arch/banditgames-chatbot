# Platform Help

## Accounts
- Users can create an account with email + password.
- If you forgot your password, use the "Reset Password" link on the login screen.

## Starting a game
1. Choose a game from the library page.
2. Click "Start Game" (or "Create Lobby" for multiplayer).
3. Invite friends using the lobby code.

## Navigation
- Library: browse games
- My Games: recently played
- Profile: account + settings
- Support: FAQs and contact form
